# 건축 트랙 이미지 폴더

이 폴더에 아래 파일명으로 이미지를 넣으면 페이지에 자동으로 표시된다.
파일이 없으면 점선 자리표시자가 그대로 보이며, HTML은 고칠 필요가 없다.

== 필요한 파일 ==

a. profile.jpg
   수행자 소개(WHO) 섹션의 프로필 사진. 세로형(3:4) 권장, 가로 600px 이상.

b. concept-01.jpg ~ concept-06.jpg
   결과물(DELIVERABLES) 섹션의 컨셉 이미지 6컷. 가로형(4:3) 권장, 가로 1000px 이상.
   현재 걸어 둔 설명 문구는 아래 순서다. 실제 이미지와 맞게
   architecture-studio/index.html 의 figcaption 내용을 수정한다.

   01. 디자인 컨셉 보드 — 무드·자재·조명 방향
   02. 3D 모델링 뷰 — 시선 높이 뷰 3컷 이상
   03. 평면 대안 비교 — 동선·수납·좌석 수 대안
   04. 입면 · 파사드 계획안 — 외부 면과 간판 위치
   05. 실시도면 부분 상세 — 시공 지시 수준
   06. 견적설계 · 물량 산출표 — 항목별 수량 근거

== 주의 ==

1. 발주처 보안 정책상 공개가 제한되는 도면은 치수·상호를 지운 부분 컷으로 쓴다.
2. 파일 용량은 컷당 400KB 이하로 줄여서 넣는다(모바일 로딩 속도).
3. 파일명은 위 목록과 정확히 같아야 한다(소문자, 확장자 .jpg).
