# PHILIP STUDIO 21cm 정사각 프로모션 홍보물 안내

== 파일 목록 ==

a. promo-square-21cm.pptx — 편집 원본. 슬라이드 4장, 각 장이 21 x 21 cm 한 면
b. promo-square-21cm.pdf — 인쇄용 출력. PowerPoint에서 그대로 내보낸 파일

== 구성 ==

두 개의 축을 교차해 네 장을 만들었다. 트랙 축은 건축과 IT, 서비스 축은 용역(외주)과 교육(강의)이다.

1. 1장 건축 x 용역 — 도면 없이 받은 견적은 애초에 비교할 수 없습니다
   PACKAGE A 45만원~ / PACKAGE B 140만원~ / PACKAGE C 350만원~ / 점검 · 검증 · 연간 자문 회당 30만원~
2. 2장 건축 x 교육 — 대신 판단해 드리는 것이 아니라, 판단의 기준을 옮겨 드립니다
   LEVEL 01 기초 스케치업 · 웹툴 / LEVEL 02 도면 읽고쓰기 / LEVEL 03 시공관리 포인트 / LEVEL 04 셀프 시공 코칭
3. 3장 IT x 용역 — 만드는 사람과 운영하는 사람이 같습니다
   STANDARD 90만원~ / DELUXE 240만원~ / PREMIUM 600만원~ / 기업 AI 도입 진단 150만원~ · 구축 300만원~
4. 4장 IT x 교육 — 대신 만들어 드리는 것이 아니라, 판단의 기준을 옮겨 드립니다
   LEVEL 01 IT 핵심 / LEVEL 02 IT Deep Dive / LEVEL 03 원리부터 AI / LEVEL 04 AI 실전세션

모든 문구, 가격, 연락처는 brochure-architecture.html 과 brochure-it.html 의 내용을 그대로 옮겼다.
두 브로슈어의 법적 고지(건축사 업무 범위, 법정 정기점검, 교육의 범위)는 각 장 하단 작은 글씨로 유지했다.

== 디자인 규칙 ==

a. 색과 형태 언어는 business-cards 와 promotionBrochure 의 브랜드 규칙을 따른다.
   건축은 짙은 그린(#0A3711)과 금색(#C9A227), 직각 모서리, 얇은 금색 프레임과 확장 직선 엠블럼.
   IT는 블루 팔레트(#CEDEF2 ~ #023373), 라운드 모서리, 원 안의 동심 아치 엠블럼.
b. 용역 장은 어두운 바탕, 교육 장은 흰 바탕이다. 한눈에 두 서비스가 구분되도록 바탕색을 갈랐다.
c. 레이아웃 구조는 business_proposal_split_template.pptx 에서 가져왔다.
   상단 사진 밴드 위 큰 헤드라인, 01~04 번호 카드 2 x 2 그리드, 좌측 세로 컬러 바, 엠블럼 + 워드마크, 하단 연락처 푸터.
d. 상단 사진 4장은 그 템플릿의 media 이미지 중 글자가 없는 영역만 잘라 쓰고, 트랙 색 오버레이를 덮었다.
   원본 해상도가 1920 px 폭이라 21cm 폭 기준 약 100 dpi 이다. 오버레이 아래 질감으로만 쓰이므로 인쇄에 문제는 없지만,
   사진을 선명하게 드러내고 싶으면 더 큰 원본으로 교체해야 한다.
e. 서체는 맑은 고딕(Malgun Gothic)이다. 브랜드 1순위 서체인 Pretendard가 이 PC에 설치되어 있지 않아 대체했다.
   Pretendard를 설치한 뒤 pptx에서 글꼴 바꾸기를 하면 브로슈어와 서체가 통일된다.

== 인쇄 ==

a. 재단 크기 210 x 210 mm. pdf 페이지가 정확히 이 크기다.
b. 재단 여유(bleed)는 포함하지 않았다. 인쇄소가 사방 3 mm 여유를 요구하면 pptx에서 슬라이드 크기를 216 x 216 mm로 키우고
   배경 사각형과 사진 밴드, 좌측 세로 바만 가장자리까지 늘리면 된다. 글자는 모두 가장자리에서 14 mm 안쪽에 있어 재단에 안전하다.
c. 배경이 어두운 1장과 3장은 잉크 사용량이 많으므로 무광 코팅 용지를 권한다.

== 수정할 때 ==

a. 문구와 가격은 pptx에서 해당 글상자를 직접 고친다. 모든 요소가 네이티브 도형과 글상자라 편집이 자유롭다.
b. 사진을 바꾸려면 상단 밴드의 그림을 선택해 그림 바꾸기를 한다. 밴드 비율은 21 : 8.6 이다.
c. 고친 뒤에는 PowerPoint의 내보내기로 pdf를 다시 만든다. 기존 pdf는 pptx의 사본이므로 함께 갱신해야 한다.
