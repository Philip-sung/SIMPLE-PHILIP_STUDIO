# PHILIP STUDIO 홍보 브로슈어 인쇄 안내

== 파일 목록 ==

a. brochure-architecture.html — 건축 트랙 6장 (짙은 그린 + 금색)
b. brochure-it.html — IT 트랙 6장 (블루 팔레트 + 라운드)

두 파일 모두 외부 자원을 참조하지 않는 단일 HTML이다. 인터넷 연결 없이 열리며,
파일 하나만 전달해도 상대방 컴퓨터에서 동일하게 보인다.

== 규격 ==

a. 용지 A4 가로 (landscape), 297 x 210 mm
b. 페이지 여백 0, 본문 안쪽 여백 상하 14mm 좌우 16mm
c. 각 장은 정확히 A4 한 면에 고정되며, 내용이 넘치지 않도록 높이를 잠가 두었다
d. 총 6장 (표지 1장 + 본문 5장)

== 인쇄 방법 ==

1. 브라우저(Chrome, Edge 권장)로 html 파일을 연다
2. 상단의 "인쇄 · PDF로 저장" 버튼을 누르거나 Ctrl+P 를 누른다
3. 대상: 프린터 또는 "PDF로 저장"을 고른다
4. 용지 크기: A4
5. 방향: 가로
6. 배율: 100% (맞춤 축소 아님)
7. 여백: 없음
8. 배경 그래픽: 켜기 — 이 항목을 끄면 표지의 색 면과 강조 블록이 흰색으로 빠진다
9. 인쇄 실행

상단 안내바는 인쇄물에 나오지 않는다. 화면에서만 보이는 조작용 막대다.

== 용역과 교육의 분리 ==

용역과 교육은 결과물도 절차도 다른 별개의 서비스이므로, 브로슈어에서도 지면을 나눠 소개한다.
3장과 4장이 용역이고 5장이 교육이며, 각 장 머리말에 "용역" 또는 "교육"을 표기해 구분한다.
6장의 진행 방식도 외주 절차와 교육 절차를 두 줄로 나눠 보여 준다.

용역은 결과물이 코드 또는 도면이고, 교육은 결과물이 수강자의 판단력이다.
교육 지면에는 "대신 해 드리는 것이 아니라 판단의 기준을 옮겨 드린다"는 성격을 명시했다.

== 장별 메시지 ==

건축 트랙
1. 표지 — 도면 없이 받은 견적은 애초에 비교할 수 없습니다
2. 왜 도면인가 — 시공사마다 말이 다른 이유는 기준 도면이 없기 때문입니다
3. 용역 01 설계 패키지 — 실측부터 견적설계까지 한 사람이 연결합니다
4. 용역 02 점검 검증 자문 — 지어진 뒤에도 판단의 기준은 계속 필요합니다
5. 교육 공간 건축 강의 — 대신 판단해 드리는 것이 아니라 판단의 기준을 옮겨 드립니다
6. 진행 방식 — 범위를 문서로 확정한 뒤에 시작합니다

IT 트랙
1. 표지 — 만드는 사람과 운영하는 사람이 같습니다
2. 신뢰의 근거 — 경력의 길이가 아니라 지금 운영 중인 서비스가 증명합니다
3. 용역 01 웹 앱 개발 외주 — 범위를 문서로 확정한 뒤 고정가로 만듭니다
4. 용역 02 기업 AI 도입 — 도입할지를 묻기 전에 어디에 쓸지를 먼저 정합니다
5. 교육 AI IT 강의 — 대신 만들어 드리는 것이 아니라 판단의 기준을 옮겨 드립니다
6. 진행 방식 — 문서로 시작해서 문서로 끝냅니다

== 수정할 때 ==

가격, 실적, 연락처는 html 파일 안의 해당 문구를 직접 고치면 된다.
색은 파일 상단 style 블록의 :root 변수만 바꾸면 전체에 반영된다.

건축: --green(#0A3711) --gold(#C9A227)
IT: --c1(#CEDEF2) --c2(#A0C4F2) --c3(#6DA7F2) --c4(#035AA6) --c5(#023373)

문구를 늘리면 해당 장이 A4 한 면을 넘길 수 있다. 늘린 뒤에는 반드시 인쇄 미리보기로
그 장이 두 면으로 쪼개지지 않는지 확인한다.

== 법적 고지 (건축 트랙) ==

건축 브로슈어 6장 하단의 "업무 범위의 한계"는 건축사법과 건축법에 따른 방어 문구다.
허가 신고 대상 설계와 공사감리가 건축사의 업무임을 명시하고, 대수선에 해당하는 공사는
별도 신고와 건축사사무소 설계가 필요함을 알린다. 이 문단은 지우지 않는다.

같은 이유로 브로슈어는 홈페이지와 달리 "정기점검" 대신 "육안 상태점검"을,
"구조안전 셀프진단" 대신 교육 성격을 드러내는 표현을 쓴다. 건축물관리법상 정기점검은
지정 점검기관만 수행할 수 있는 법정 업무이기 때문이다.

건축 4장 하단의 "업무의 성격"과 5장 하단의 "교육의 범위"도 같은 목적의 문단이다.
전자는 육안 점검이 법정 정기점검을 대체하지 않음을, 후자는 강의가 시공 대행이나 감리가
아님을 밝힌다. 두 문단 모두 지우지 않는다.
